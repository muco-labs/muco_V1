# SOP framework (templates only)

Create real SOPs outside production data. Suggested files:

| SOP | Owner (assign externally) |
|-----|---------------------------|
| Lead handling | Sales |
| Proposal send | Sales + Founder approval |
| Project kickoff | Delivery |
| Development / QA / deploy | Engineering |
| Support triage | Support |
| Invoice & payment | Finance |
| Employee offboarding | People / Founder |

Each SOP should link to the matching admin workflow in the app (CRM, projects, invoices, etc.).

**Do not paste legal or HR policy text here without counsel.**
