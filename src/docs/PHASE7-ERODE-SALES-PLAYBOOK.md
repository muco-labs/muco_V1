# Erode segment — sales playbook (internal)

## Stages

1. **Lead** — Website inquiry, referral, or manual entry; check Erode segment in Admin → Erode market.  
2. **Qualification** — Budget range, timeline, decision maker, problem (website vs software vs SEO).  
3. **Discovery** — 30–45 min call; confirm scope, integrations, content ownership.  
4. **Service match** — Map to national service page; use local `/erode/*` page only as context.  
5. **Proposal** — Use existing proposal flow; no guaranteed rankings or fake urgency.  
6. **Follow-up** — CRM follow-up dates; log calls in lead activity.  
7. **Close / Won** — Convert to customer; trigger referral ask when appropriate (Phase 6).

## Qualification prompts

- What does success look like in 90 days?  
- Who maintains content after launch?  
- Any compliance needs (healthcare, education data)?  
- Preferred communication: on-site in Erode vs remote?
