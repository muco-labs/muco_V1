# Internal knowledge base (structure)

Authorized employees only (future: gated docs or Notion/Confluence).

```
knowledge-base/
  company/     — mission, org chart (when real)
  engineering/ — stack, deploy, security
  design/      — brand, components
  sales/       — playbooks
  marketing/   — SEO inventory pointers
  support/     — ticket standards
  operations/  — vendors, DR
  product/     — Client Hub validation notes
```

Content is maintained manually; this repo holds pointers and architecture docs under `src/docs/`.
